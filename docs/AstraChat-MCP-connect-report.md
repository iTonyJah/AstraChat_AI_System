# Отчёт о запуске mcp-powerpoint (Генерация презентаций .pptx)

## Языковая модель была переключена на внешний API от АлиБабы.
(чтобы не перегревать процессор)

## В качестве mcp-сервера было выбрано готовое решение с MIT лицензией
https://github.com/GongRzhe/Office-PowerPoint-MCP-Server

Проект заморожен 3 марта 2026 года, но чтобы полностью исключить изменения на ГитХабе был сделан форк:
https://github.com/iTonyJah/Office-PowerPoint-MCP-Server

Далее клонирован с изменением целевой папки на 'mcp-powerpoint'.

Далее были изменены настройки для запуска в ифнраструктуре AstraChat.
(в том числе добавлены два новых инструмента, получить список сохранённых презентаций и удалить сохранённые презентации)

## Итог
Инструмент доступен из пользовательсого UI со следующими особенностями:

1. Часто запрос уходит на сторону генерации изображений, которая у меня была отключена. "Не удалось сгенерировать изображение: Не удалось получить список моделей ComfyUI:"

2. Генерирует и сохраняет файл презентации. Может добавить слайд. Может исправить конкретный слайд. Удалить слайд не может. Слайд не видит, текст уезжает за границы.

2.1 Работает, как 'root', поэтому сохранённые файлы не доступны для редактирования и удаления обычным пользователе без 'sudo'.
```
itj@fedora:~/AstraChat_AI_System$ ls -lh ./assets/pptx_output/
итого 36K
-rw-r--r--. 1 root root 34K июл 26 10:39 mcp_powerpoint_tools.pptx
```

2.2 Включенный инструмент сразу добавляет 13,1k токенов в первый запрос.
